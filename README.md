# 阿輝英文日課（english）

個人自用的英文學習 PWA：每日打卡（Funday、Speak、閱讀、複習分鐘數與連續天數）、單字本（快速加入、單字卡、類似 Anki 的間隔複習、瀏覽器內建朗讀）、每週閱讀清單（難度、生字預習、簡化版、原文連結、讀完感受與一句中文重點）、手機與平板雲端同步（自己的 Google 雲端硬碟）。

資料只存在使用者自己的瀏覽器與自己的雲端硬碟，**本 repo 不含任何文章、單字或個人資料**；閱讀清單只連到原文網址。

- 同步：使用者自己部署的 Google Apps Script（網址＋自訂密語）。
- 圖示：程式產生。
- 程式：Claude Code 協助開發。
