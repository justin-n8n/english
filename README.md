# 阿輝英文日課（english）

個人自用的英文學習 PWA（v0.6.1）：每日打卡（今天三步、Funday、Speak、閱讀、複習分鐘數、連續天數、補記前 3 天）、每日勵志小語與附出處的名言、自己從書裡記下的小語、閱讀（每週閱讀清單、每日 A2 新聞、圖文學習單、資源連結；點字加入單字本、選擇題）、單字本與字庫（依主題、子主題進學習頁的字庫與片語、每個字已讀／還沒讀、快速加入、自動分類、類似 Anki 的間隔複習）、聽與說（瀏覽器內建朗讀、連續播放、跟讀＝瀏覽器語音辨識）、進度頁（學習月曆、單字已讀／收集／學會、每週成長、里程碑）、手機與平板雲端同步（自己的 Google 雲端硬碟）。

資料只存在使用者自己的瀏覽器與自己的雲端硬碟，**本 repo 不含任何文章或個人資料**；閱讀內容、字庫、片語與每日小語都由使用者自己的雲端同步進來，不在這個 repo 裡；文章只連到原文網址。唯一的例外是 `wordlist.js`：公開發布的官方字表（教育部國中小基本 1200 字、大考中心高中英文參考詞彙表），只有字和級別，用來替單字分類。

- 同步：使用者自己部署的 Google Apps Script（網址＋自訂密語）。

- 程式：Claude Code 協助開發。
